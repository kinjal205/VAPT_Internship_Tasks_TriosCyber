# Task 01 - Kali Linux Lab Setup & Network Enumeration

## Objective

To set up a Kali Linux lab environment and use basic Linux and networking commands to identify system and network information.

## Tasks Performed

- Set up Kali Linux lab environment
- Identified the system hostname using `hostname`
- Identified the current user using `whoami`
- Identified network interfaces and IP address using `ip a`
- Checked network configuration using `ifconfig`
- Identified the default gateway using `ip route`
- Tested network connectivity using `ping`
- Identified listening ports and services using `ss -tulnp`

## Tools & Technologies

- Kali Linux
- Linux Terminal
- Whoislookup
- Nmap

## Key Findings

- Hostname: `kali`
- Current User: `kali`
- Active Interface: `eth0`
- IP Address: `192.168.248.131`
- Default Gateway: `192.168.248.2`
- Connectivity: Successful ping to `8.8.8.8` with 0% packet loss
- Listening Service: Mosquitto on TCP port `1883`

## Key Learnings

- Basic Kali Linux system identification
- Network interface and IP address enumeration
- Understanding default gateway and routing information
- Testing network connectivity
- Identifying listening ports and services
