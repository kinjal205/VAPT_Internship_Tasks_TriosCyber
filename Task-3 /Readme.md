# Task 3 – Network Scanning & Packet Analysis

VAPT Internship – TriosCyber

## Overview

This task was completed as part of my VAPT Internship at TriosCyber.

The objective of this practical was to perform targeted TCP and small UDP network scans using Nmap, identify running services on an authorized Metasploitable target, and capture and analyze the generated network traffic using Wireshark.

## Objectives

- Perform targeted TCP SYN scanning using Nmap
- Perform a small authorized UDP scan
- Identify open ports and running services
- Perform service version detection
- Capture network traffic generated during scanning
- Analyze TCP SYN packet communication using Wireshark
- Analyze UDP packets and ICMP responses using Wireshark
